# Alarmpro 0.8.1

Changes since 0.7.4:

- Redesigned the alarm editor with clearer repeat, date, group, sound, and snooze controls, plus a live countdown to the next alarm.
- Improved one-time scheduling when alarms are created or re-enabled, and added an option to delete them after dismissal.
- Added optional **Check I'm awake** prompts after dismissal, with a configurable delay and a re-ring if there is no response.
- Expanded export and import to include settings and stopwatch state, while keeping older backups compatible.
- Improved stopwatch time display for long sessions and enlarged its main controls.
- Improved custom alarm sound names and wake-check delivery over the lock screen and other apps.
